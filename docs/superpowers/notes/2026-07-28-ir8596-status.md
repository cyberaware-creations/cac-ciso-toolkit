## Two things worth recording

**The `/ipd` check was the point of this task.** A search result carried the title *"NIST IR
8596 **ipd** …"* on an NCCoE page — `ipd` is *initial public draft*, a newer stage than `iprd`.
Had one existed, the priorities could have moved and T9's 318 hand-verified values would have
been extracted from a superseded document. `csrc.nist.gov/pubs/ir/8596/ipd` returns 404, and
CSRC is authoritative for publication stage, so the NCCoE title is loose naming rather than a
second draft.

**The NCCoE pages could not be read** — both returned 403 to an automated fetch. So this note
rests on CSRC plus search-result summaries, not on NCCoE directly. If a human can open
`nccoe.nist.gov/projects/cyber-ai-profile` in a browser, that is worth one look before T8
starts. Recorded as a limit of this check rather than glossed.

**The design's recorded source URL is wrong.** It carries
`https://csrc.nist.gov/pubs/ir/8596` (404). The dataset's `sourceUrl` should be the DOI
`https://doi.org/10.6028/NIST.IR.8596.iprd` or the `/iprd` landing page — not the bare number.
